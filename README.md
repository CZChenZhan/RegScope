# $\text{RegScope}$ 项目说明

---

## 项目简介

&emsp;&emsp;这是一个面向 $\text{Windows}$ 注册表分析场景的桌面工具，基于 $\text{Qt}$ 与 $\text{C++17}$ 实现。项目围绕注册表浏览、快照拍摄、快照对比、实时事件分析、结果导出与配置过滤展开，适合用于系统行为观察、安装前后差异比对、可疑改动排查与基础取证辅助。

&emsp;&emsp;项目基于已有开源项目 $\text{Regshot}$ 及其 $\text{GitHub fork: Regshot-advance}$ 重写。

---

## 核心能力

- **注册表浏览**
&emsp;&emsp;支持在左侧树形区域查看主要根键，并按需展开子键
- **键值详情查看**
&emsp;&emsp;支持在右侧区域展示当前键下的键值内容与文本化结果
- **注册表搜索**
&emsp;&emsp;支持在详情区内搜索关键字，并在结果之间跳转
- **注册表过滤**
&emsp;&emsp;支持输入过滤规则，减少无关结果干扰
- **快照拍摄**
&emsp;&emsp;支持生成 $\text{.rgs}$ 快照文件，也支持以内存方式完成两次快照采集
- **快照比较**
&emsp;&emsp;支持对两份快照进行差异分析，输出新增键、删除键、新增值、删除值、修改值等结果
- **实时分析**
&emsp;&emsp;支持基于 $\text{ETW}$ 监听注册表变化，并记录时间、动作、键路径、值内容、进程信息与命令行信息
- **风险等级过滤**
&emsp;&emsp;支持按 $\text{1}$ 到 $\text{5}$ 的危险等级加载不同规则文件，控制分析粒度，同时支持自定义的过滤文件填入
- **结果保存**
&emsp;&emsp;支持将快照比较结果或实时分析结果保存为文本文件
- **中英文界面**
&emsp;&emsp;支持中文与英文切换，界面文案已考虑双语显示

## 技术方案

### 开发框架与语言

- 图形界面基于 $\text{Qt Widgets}$
- 并发任务基于 $\text{Qt Concurrent}$
- 代码标准采用 $\text{C++17}$
- 构建系统使用 $\text{CMake}$

### 核心模块
- **快照对比模块**：由 $\text{RegShot}$ 模块实现，处理快照序列化与差异计算
- **实时监控模块**：由 $\text{RegistryMonitor}$ 模块实现，基于 $\text{ETW}$ 技术实现高性能监听

### 外部依赖
- 主要依赖 Windows 系统库：$\text{advapi32}$、$\text{tdh}$、$\text{wbemuuid}$、$\text{ole32}$、$\text{oleaut32}$

---

## 运行环境

- **操作系统**：建议为 $\text{Windows 10}$ 或更高版本
- **构建环境**：建议为 $\text{Qt 6}$ 或兼容的 $\text{Qt 5}$
- **编译器**：建议为支持 $\text{C++17}$ 的 $\text{MSVC}$
- **权限要求**：进行实时分析时，必须以管理员权限运行程序

## 获取与安装

### 如何下载
- **源码获取**
&emsp;&emsp;可以通过 $\text{git}$ 客户端克隆本仓库到本地
- **发行版获取**
&emsp;&emsp;在仓库的 $\text{Releases}$ 页面下载预编译好的压缩包，解压后即可直接运行

### 如何使用
- **启动程序**
&emsp;&emsp;双击 $\text{RegScope.exe}$ 启动。若需实时分析功能，请右键选择以管理员身份运行
- **浏览注册表**
&emsp;&emsp;在左侧树状图中点击根键进行展开，点击具体项可在右侧查看详细内容
- **快照对比**
&emsp;&emsp;点击分析菜单下的拍摄快照，完成两次拍摄后，程序将自动分析并展示差异
- **实时分析**
&emsp;&emsp;在分析菜单中选择开始分析，设定风险等级后即可实时观察系统注册表变动

---

## 操作指南

### 基础浏览流程
&emsp;&emsp;1. 启动程序后，左侧显示注册表树
&emsp;&emsp;2. 选择某个节点后，右侧显示该节点及其子项的键值内容
&emsp;&emsp;3. 底部区域显示运行日志与状态信息

### 快照分析流程
&emsp;&emsp;1. 执行首次快照拍摄
&emsp;&emsp;2. 执行第二次快照拍摄，或加载已有快照文件
&emsp;&emsp;3. 启动快照比较功能
&emsp;&emsp;4. 在结果区查看统计概览与差异明细
&emsp;&emsp;5. 将结果保存到文本文件

### 实时分析流程
&emsp;&emsp;1. 确保已切换到管理员权限
&emsp;&emsp;2. 选择风险等级与配置文件
&emsp;&emsp;3. 启动实时分析
&emsp;&emsp;4. 在结果区查看摘要与事件明细
&emsp;&emsp;5. 任务结束后保存分析结果

## 配置与目录

### 配置说明
&emsp;&emsp;项目内置多组配置文件，用于控制默认行为与分析过滤：
- **$\text{default.ini}$**：保存语言、结果目录、默认保存目录等基础设置
- **$\text{user.ini}$**：用于保存用户运行期配置
- **$\text{filter.ini}$**：用于维护应跳过的注册表路径，减少高频系统噪声
- **$\text{level1.ini}$ 到 $\text{level5.ini}$**：用于表示不同危险等级的分析规则

### 目录结构
- **$\text{RegScope/}$**：主程序源码目录
- **$\text{main.cpp}$**：程序入口与界面语言加载
- **$\text{mainwindow.cpp}$ 与 $\text{mainwindow.h}$**：主界面与主要业务逻辑
- **$\text{regshot.cpp}$ 与 $\text{regshot.h}$**：注册表快照、序列化、加载与对比逻辑
- **$\text{registrymonitor.cpp}$ 与 $\text{registrymonitor.h}$**：基于 $\text{ETW}$ 的实时事件监听逻辑
- **$\text{configs/}$**：配置文件目录
- **$\text{styles/}$**：界面样式目录
- **$\text{pictures/}$**：图标资源目录

---

## 数据输出

&emsp;&emsp;程序会生成以下几类结果：
- 注册表快照文件，扩展名为 $\text{.rgs}$
- 文本分析结果，便于归档、检索与复核
- 实时分析摘要与事件明细
- 快照差异统计与变更列表
